# Hiy-UI

Hiy-UI is a C++20 UI library built on LVGL 9. The public API covers widgets, layout, styling, theming, windows, and platform adaptation.

## Reading order

1. [Overview](/en/guide/introduction). Scope and repository structure.
2. [Quick Start](/en/guide/quick-start). Build and run a minimal application.
3. [Application](/en/core/application). Application entry point and window creation.
4. [Widget syntax](/en/core/syntax-design). Props, container mounting, and chained methods.
5. [Layout widgets](/en/widgets/layout). Box, VBox, HBox, FlowBox, and Spacer.

After finishing Quick Start, consult the widget, styling, or window sections by task. Interface signatures, default values, and member lists are in the [API Reference](/en/api-reference/).

## Example programs

The component gallery entry point is `test/demo/component_gallery/main.cpp`; each widget page lives in the `pages` subdirectory next to it.
