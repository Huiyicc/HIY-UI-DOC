# EmbedSvg <Badge type="info" text="Class" />

**Header:** `#include <hiyui/misc/embed_svg.h>`

**Namespace:** `hiyui`

Embedded SVG resource descriptor

Pre-rasterizes the SVG to an ARGB8888 bitmap through lunasvg. Internally owns the pixel buffer, whose lifetime must cover every widget referencing the image.


Supports tintColor accent overlay, which replaces the RGB channels of non-transparent pixels and keeps the original alpha.
