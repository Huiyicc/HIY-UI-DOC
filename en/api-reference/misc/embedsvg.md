# EmbedSvg <Badge type="info" text="Class" />

**Header:** `#include <hiyui/misc/embed_svg.h>`

**Namespace:** `hiyui`

Embedded SVG resource descriptor

Pre-rasterizes the SVG to an ARGB8888 bitmap through lunasvg. Holds the pixel buffer internally; its lifetime must cover all widgets referencing this image.


Supports tintColor accent overlay, replacing RGB channels of non-transparent pixels while keeping the original alpha.
