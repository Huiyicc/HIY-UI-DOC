# EmbedPng <Badge type="info" text="Class" />

**Header:** `#include <hiyui/misc/embed_png.h>`

**Namespace:** `hiyui`

Embedded PNG resource descriptor

Instances with the same array address and length share a descriptor. The array must remain immutable, and both the array and at least one owning instance must outlive all component references.
