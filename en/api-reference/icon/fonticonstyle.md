# FontIconStyle <Badge type="info" text="Struct" />

**Header:** `#include <hiyui/icon/font_icon.h>`

**Namespace:** `hiyui`

Variable Font axis parameters.

Material Symbols supports four variable axes: FILL 0 for outline or 1 for fill, wght 100 to 700 for weight. GRAD ranges from -25 to 200 for grade, opsz from 20 to 48 for optical size.
