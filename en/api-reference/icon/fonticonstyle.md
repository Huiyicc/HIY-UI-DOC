# FontIconStyle <Badge type="info" text="Struct" />

**Header:** `#include <hiyui/icon/font_icon.h>`

**Namespace:** `hiyui`

Variable Font axis parameters.

Material Symbols supports four variable axes. FILL, 0 for outline or 1 for filled. wght, 100 to 700, weight. GRAD, -25 to 200, grade. opsz, 20 to 48, optical size.
