# FontIcon <Badge type="info" text="Class" />

**Header:** `#include <hiyui/icon/font_icon.h>`

**Namespace:** `hiyui`

Material Symbols icon font renderer, global singleton.

Loads the Variable Font directly through the FreeType API and renders codepoints into lv_image_dsc_t. An internal render cache avoids rendering again with identical parameters.

## Static Methods

### instance

```cpp
static FontIcon & instance()
```

Returns the global singleton

## Public Methods

### init

```cpp
bool init(const unsigned char *data, unsigned int size)
```

Initializes the font from embed memory data

data is not copied and must stay valid until the next init or process end. Passing the same data and size again is a no-op. Passing different data releases the current font and all render caches, and pointers previously returned by render() become invalid.


Font byte array generated by embed Data size On failure FontIcon stays uninitialized and ready() is false

### ready

```cpp
bool ready() const
```

Whether initialized

### render

```cpp
const lv_image_dsc_t * render(uint32_t codepoint, uint32_t sizePx, const FontIconStyle &style={})
```

Renders an icon by codepoint

The returned lv_image_dsc_t pointer is managed by the FontIcon internal cache. It lives as long as the FontIcon instance, until clearCache or destruction.


Unicode codepoint, such as HIYUI_ICON_HOME Render size in pixels Variable Font axis parameters Pointer, nullptr on failure

### clearCache

```cpp
void clearCache()
```

Clears all render caches
