# hiyui_frame_navigation_toggle_props_t <Badge type="info" text="结构体" />

**头文件：** `#include <hiyui/c/layout.h>`

导航切换按钮创建属性。

## 公开成员

### icon_codepoint

```c
uint32_t icon_codepoint
```

图标码点，0 使用 HIYUI_ICON_MENU。

### icon_size

```c
uint32_t icon_size
```

图标逻辑尺寸，0 使用 20。

### size

```c
int size
```

按钮逻辑尺寸，0 使用 40。

### bg

```c
uint32_t bg
```

按钮背景色，0 跟随主题。

### text_color

```c
uint32_t text_color
```

图标颜色，0 跟随主题。
