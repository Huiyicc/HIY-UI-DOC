# BoxProps <Badge type="info" text="结构体" />

**头文件：** `#include <hiyui/widget/box.h>`

**命名空间：** `hiyui`

`Box` 创建属性

## 公开成员

### width

```cpp
int width
```

宽度，HIYUI_AUTO = 自适应内容

### height

```cpp
int height
```

高度，HIYUI_AUTO = 自适应内容

### bg

```cpp
uint32_t bg
```

背景色，HIYUI_DEFAULT = 跟随主题

### radius

```cpp
int radius
```

圆角半径

### borderWidth

```cpp
int borderWidth
```

边框宽度

### borderColor

```cpp
uint32_t borderColor
```

边框颜色，HIYUI_DEFAULT = 跟随主题

### padding

```cpp
int padding
```

内边距

### margin

```cpp
int margin
```

外边距，容器在父布局中的外边距
