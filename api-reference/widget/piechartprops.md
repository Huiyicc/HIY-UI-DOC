# PieChartProps <Badge type="info" text="结构体" />

**头文件：** `#include <hiyui/widget/chart/pie_chart.h>`

**命名空间：** `hiyui`

饼图创建属性

**继承自：** `hiyui::ChartBaseProps`

## 公开成员

### innerRadius

```cpp
int innerRadius
```

&gt;0 时为环形图，甜甜圈，单位像素

### startAngle

```cpp
int startAngle
```

起始角度，度，-90 = 12 点钟方向

### sliceGap

```cpp
int sliceGap
```

扇区间隔角度

### showPercent

```cpp
bool showPercent
```

是否显示百分比文字
