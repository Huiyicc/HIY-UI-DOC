# FrameNavigationToggleProps <Badge type="info" text="结构体" />

**头文件：** `#include <hiyui/widget/window_frame.h>`

**命名空间：** `hiyui`

导航切换按钮创建属性。

## 公开成员

### iconCodepoint

```cpp
uint32_t iconCodepoint
```

图标码点，0 使用 HIYUI_ICON_MENU。

### iconSize

```cpp
uint32_t iconSize
```

图标逻辑尺寸，0 使用 20。

### size

```cpp
int size
```

按钮逻辑尺寸，0 使用 40。

### bg

```cpp
uint32_t bg
```

按钮背景色。

### textColor

```cpp
uint32_t textColor
```

按钮图标颜色。
