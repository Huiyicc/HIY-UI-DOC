# FontScale <Badge type="info" text="结构体" />

**头文件：** `#include <hiyui/style/theme.h>`

**命名空间：** `hiyui`

字体大小预设，覆盖 xs ~ xxl 六个级别

## 公开成员

### xs

```cpp
int xs
```

超小号字体

### sm

```cpp
int sm
```

小号字体

### md

```cpp
int md
```

中号字体，默认

### lg

```cpp
int lg
```

大号字体

### xl

```cpp
int xl
```

超大号字体

### xxl

```cpp
int xxl
```

特大号字体
