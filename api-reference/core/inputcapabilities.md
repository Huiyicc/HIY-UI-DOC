# InputCapabilities <Badge type="info" text="结构体" />

**头文件：** `#include <hiyui/core/responsive.h>`

**命名空间：** `hiyui`

后端当前接入的交互设施，多项可以同时可用。

## 公开成员

### pointer

```cpp
CapabilityState pointer
```

不包含触摸模拟鼠标。

### keyboard

```cpp
CapabilityState keyboard
```

包含后端接入的屏幕键盘。
