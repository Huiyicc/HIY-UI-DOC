# XmlDocumentMetadata <Badge type="info" text="结构体" />

**头文件：** `#include <hiyui/xml/xml_schema.h>`

**命名空间：** `hiyui`

XML 文档级元素的 Schema 描述。

## 公开成员

### layoutRules

```cpp
XmlWidgetMetadata layoutRules
```

布局附件描述；与 layoutRule 同时为空表示未声明规则。

### layoutRule

```cpp
XmlWidgetMetadata layoutRule
```

单个宿主尺寸条件。
